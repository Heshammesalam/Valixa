# Valixa 1.0.0-rc.1 — prepared, not published

Candidate for the first stable 1.0.0 release. Eleven packages use one fixed version
train: core, React/MUI, Vue/Vuetify, Angular/Material, headless Auto/DevTools and
dedicated Angular Auto/DevTools. All are scoped under @valixa.

The candidate contains the existing Phase 1–6 product APIs. Release stabilization
adds verified metadata and compatible internal ranges, Angular package file-list
normalization, tarball checksums/content inspection, immutable action pins, protected
manual OIDC release automation, current security fixes in build/test tools, additional
installed production consumers, Firefox/WebKit execution and native hydration/security
regressions. No product features or intentional public API breaks are added.

Before publishing review docs/phase-7-release-readiness.md and docs/releasing.md.
Important limits: ESM, explicit plain-data/codecs, installed framework peer lines,
Angular single autocomplete, optional development-only diagnostic attachment, and
the documented SSR/hydration matrix. Server validation remains mandatory.

Publication has not been confirmed. Successful local gates do not establish npm
scope ownership, trusted publisher setup, protected environment approval or Linux CI.
