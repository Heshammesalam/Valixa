# Public API

The complete [core API reference](../packages/core/API.md) ships in the npm package
alongside the declarations, source maps and sources.

Phase 2 adds [React](../packages/react/README.md) and
[Material UI](../packages/mui/README.md) API references.

Phase 3 adds [Vue](../packages/vue/README.md) and
[Vuetify](../packages/vuetify/README.md) references.

Phase 4 adds [Angular](../packages/angular/README.md) and
[Angular Material](../packages/angular-material/README.md) references.

Phase 5 adds the packaged [advanced core guide](../packages/core/ADVANCED.md):
dependency graphs/scheduling, conditional behavior, explicit nested paths, dynamic
row collections, form validation and localization. See the [implementation report](phase-5-report.md)
for tested integration scope and benchmark findings.

Phase 6 adds [Auto Form metadata](../packages/auto/README.md),
[DevTools inspection/panel](../packages/devtools/README.md), optional React/Vue/MUI/
Vuetify subpaths and dedicated [Angular Auto Forms](../packages/angular-auto/README.md)
and [Angular DevTools](../packages/angular-devtools/README.md).
The [Phase 6 guide](phase-6.md) documents capabilities, codecs, privacy and events.
